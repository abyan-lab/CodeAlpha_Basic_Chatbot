# CodeAlpha Basic Chatbot 🤖

> An interactive, rule-based command-line chatbot built as part of the CodeAlpha Python Programming internship.

![Python](https://img.shields.io/badge/Python-3.x-blue?style=flat-square&logo=python&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-green?style=flat-square)

---

## ✨ Core Features & Functionality
- **Interactive CLI:** Runs directly in the terminal, accepting user text inputs and responding in real time within a continuous loop.
- **Pattern Matching & Intent Recognition:** Utilizes conditional logic and string matching to detect keywords, greetings, and predefined FAQs.
- **Controlled Conversation Flow:** Includes clear exit conditions (e.g., typing "bye" or "quit") to gracefully terminate the dialogue loop.
- **Clean Architecture:** Designed as a lightweight foundation for future integration with advanced NLP frameworks or external APIs.
